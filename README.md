# Сложно сосредоточиться

Учебный проект Яндекс Практикума: адаптивная страница «no focus» в светлой и тёмной темах. Тема переключается автоматически по настройкам системы (`prefers-color-scheme`) или вручную кнопками «День», «Авто», «Неон». Скрипт переключения тем, шрифты и картинки выданы курсом, разметка и стили написаны мной.

Репозиторий: https://github.com/Vondre1/slozhno-sosredotochitsya-ad

## Что использовано

- Подход Mobile first, брейкпоинты 768 и 1024 пикселя.
- CSS Grid для шапки, секций и галереи, «резиновые» колонки на `fr`.
- CSS-переменные для цветов тем и размеров, размер заголовка через `clamp()`.
- Семантическая разметка, БЭМ-именование классов, ленивая загрузка картинок галереи.

## Структура

- `index.html` — разметка страницы
- `styles/variables.css` — переменные основной (тёмной) темы и размеры под разные экраны
- `styles/style.css` — основные стили и медиазапросы
- `styles/dark.css`, `styles/light.css` — переопределение переменных для тёмной и светлой тем
- `styles/globals.css` — глобальные стили и сброс отступов
- `scripts/script.js` — переключение темы
- `fonts/`, `images/` — шрифты и изображения

## Запуск

Открыть `index.html` в браузере.
